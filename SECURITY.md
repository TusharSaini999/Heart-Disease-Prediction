# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly by emailing the project maintainers. **Please do not publicly disclose the vulnerability until it has been addressed.**

### Steps to Report:
1. Go to the [Security Advisories](https://github.com/yourusername/Heart-Disease-Prediction/security/advisories) page
2. Click "Report a vulnerability"
3. Provide detailed information about the vulnerability

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Security Best Practices

When contributing to this project:
- Do not commit secrets or API keys
- Keep dependencies up to date
- Follow secure coding practices
- Report security issues privately
- Do not use hardcoded credentials

## Acknowledgments

We appreciate the security research community and those who help keep this project secure.
